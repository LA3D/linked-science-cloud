## What this enables beyond the literature wiki

The wiki supplies the research question and appraisal; the REPL supplies current, typed, executable joins and inspectable data. A concrete next experiment-planning question is: **how do L620P and R1147G differ in structural context and in separately measured transferase and glucosidase activity?** Both canonical wild-type sites exist in the retrieved experimental and predicted coordinates. The paper discusses their distinct functional regions, and Reactome supplies two distinct reaction roles. This enables a residue/assay evidence table with construct, species, numbering, assay type, units and provenance retained, followed by an explicitly scoped structural analysis. It does not establish a severity predictor or recommend a therapy.

The current UniProt feature filter for these two positions returned no matching `Natural variant`/`Mutagenesis` features; that narrow result does not negate the paper's evidence. A future assay table should use the paper's source data and verify its column semantics, rather than assume UniProt contains every measured variant. Porcine substrate-specificity findings in deck page 5 must not silently become human mechanistic measurements.

## Reproduction and operational qualifications

Use the project MCP, never the bundled generic REPL. Open a new uniquely named workspace when replaying; do not reset someone else's session. Run the exact queries in the receipt with `ws.traversal.query({sources:[{type:'sparql',value:'https://sparql.uniprot.org/sparql'}],sparql})`. Query limits were not used to hide partial results: all three completed within the default 500-result bound. Scope was narrowed by an explicit protein subject or selected schema/database terms. For local replay parse the saved P35573 Turtle or reacquire it through `resources.get` and `.rdf({name:'p35573-demo'})`.

API reads used `headers:{accept:'application/json'}`. OLS and RCSB initially returned 406 without that negotiation. Capitalized `Accept` was locally rejected by this facade; lowercase `accept` worked. The guessed ontology homepage returned HTML even when requesting RDF; it was retained as HTML and never relabeled as RDF. Schema evidence was instead queried from the endpoint. Local display limits are at most ten rows; a failed larger display does not invalidate the completed query. Graph names must be lowercase; RDF/JS Source matches must be consumed as streams.

Initial endpoint URLs and API templates were model-suggested candidates, not discovered links. The identifiers subsequently followed were explicit source evidence: UniProt → HGNC/PDB/AlphaFold/Reactome; PDB → publication DOI; publication → GDE simulation repository; Reactome pathway → reactions → catalyst → protein → UniProt. No exact-sequence search, unrelated-protein substitution, external database edit, commit, push, global configuration change or infrastructure repair occurred.

The consulted project wiki pattern `protein-assay-crosswalk-context` was proposed guidance: preserve species, constructs and relationship types. It was not used as scientific proof. No claim of demonstrated wiki benefit or generalized agent learning is made.
