This is a living experimental backlog. Status means project-local evidence only; it is not a production commitment or approval for future live access. Material work selected for execution belongs in the [active task queue](tasks/README.md), where status and handoff evidence can remain durable across Codex tasks.

## Operating boundary

An in-memory handle, a bounded display model, and a future local export are different capabilities. Context maps retain only compact metadata. Any write, export, or live trial requires its own explicit authorization. Dynamic destinations discovered during an authorized traversal are validated by the mediator rather than preapproved as an endpoint list.
